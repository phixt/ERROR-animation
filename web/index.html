ERROR-animation // NT-SCM TERMINAL

基于真实 Windows 服务控制管理器（SCM）、内存耗尽与显示内核死锁事件日志生成的终端动画。

实时合成底层持续噪声、故障门控与主板告警音，无任何外部媒体依赖。

提示：结尾包含短暂高反差闪屏与强对比视觉刺激；点击下方按钮后将开启音频并进入全屏纯终端界面。

1 - 9 跳转段落
Space 暂停 / 继续
+ / - 调节倍速 (0.4x–10x)
0 倍速复位 1.0x
Y / N 回答重试提示
M 音频静音 / 开启
C 开关 CRT 滤镜
Esc 呼出 / 关闭菜单
